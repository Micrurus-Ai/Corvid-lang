# corvid-runtime

Python runtime for code generated by the [Corvid](https://github.com/Micrurus-Ai/Corvid-lang) compiler.

Generated `.py` files import `tool_call`, `approve_gate`, and `llm_call` from this package.

> **Scope:** this package serves the Python **transpile tier only**
> (`corvid build --target=python`, the legacy tier). It dispatches
> the `@tool` implementations you register — it has **no dispatch
> for Corvid's stdlib executing tools** (io/http/db/json/time/
> random/rag/mcp). Programs that call those refuse at transpile
> time with a diagnostic; run them through the interpreter tier
> (`corvid run`), which carries the full stdlib with policies,
> tracing, and replay. See the execution-tier matrix in the book's
> Building chapter.

## Installation

```bash
pip install corvid-runtime[anthropic]
```

## Usage

You generally don't import this package directly — the Corvid compiler emits code that imports it. What you *do* write is tool implementations:

```python
from corvid_runtime import tool

@tool("get_order")
async def get_order(order_id: str):
    ...
```

## Configuration

No default model. Set one via:

- Environment: `CORVID_MODEL=claude-opus-4-6`
- Config file: `corvid.toml` with `[llm] default_model = "..."`
- Per-call: `llm_call(..., model="...")`

Approvals are interactive by default. For CI, set `CORVID_APPROVE_ALL=1`.
